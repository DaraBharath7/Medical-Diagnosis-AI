## Project Overview

Medical Diagnosis AI is a machine learning project that uses
the Breast Cancer Wisconsin dataset to classify observations
as benign or malignant based on numerical measurements.

The project demonstrates how machine learning can be applied
to medical data classification using Python.

## Objectives

- Load and explore a medical dataset.
- Prepare and preprocess the data.
- Train a machine learning classification model.
- Evaluate model performance using standard metrics.
- Visualize diagnosis distributions and model results.

## Dataset

The project uses the Breast Cancer Wisconsin dataset available
through Scikit-learn.

- Total observations: 569
- Input features: 30
- Target classes: Benign and Malignant

The dataset is loaded directly using Scikit-learn, so no
separate dataset download is required.

## Methodology

1. Import the required Python libraries.
2. Load and explore the dataset.
3. Visualize the diagnosis distribution.
4. Separate input features and target labels.
5. Split the data into training and testing sets.
6. Standardize the input features.
7. Train a Logistic Regression model.
8. Generate predictions on the testing data.
9. Evaluate the model using accuracy, precision, recall,
   F1-score, and a confusion matrix.
10. Visualize model coefficients and prediction distributions.

## Model Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix

The actual evaluation results are available in the Jupyter
notebook.
